## Global Constraints

- 每条业务命令先 `cmdutil.EnsureClient()`；请求失败用 `output.NewExitError(5, "...", "")`，JSON 解析失败用退出码 4。
- create/update 一律 `--data` JSON 直传（`cmdutil.ParseJSONData`）；查询 flag 为 kebab-case、参数 key 为 camelCase。
- 分页 flag：`--page-no`(默认1) / `--page-size`(默认20)；分页响应用 `cmdutil.ParsePagedJSON(resp.Data, pageNo, pageSize)`，非分页响应用 `cmdutil.OutputJSON(json.RawMessage(resp.Data))`。
- `@RequestParam` 型 PUT（update-status）必须用 `cmdutil.GetClient().PutQuery(...)`（client.go:75），不能用 Put（那是 JSON body）。
- 时间范围参数折叠为 `{paramKey}[0]/{paramKey}[1]`；结算日期复用既有 `cmdutil.AddSettlementDateFlags/CollectSettlementDate`（flag 名 `--start-date/--end-date`，与 settlement main 保持一致——spec 中 A1 的 `--start-time/--end-time` 表述据此修正为 `--start-date/--end-date`）。
- 测试风格对齐 `cmd/order/order_prepayment_test.go`：flag 存在性 + 子命令存在性（不 mock HTTP）。
- commit 遵循 conventional commits，中文描述（历史惯例）。

```go
package cmdutil

import "github.com/spf13/cobra"

// AddTimeRangeFlags 注册 --<flagName>-start / --<flagName>-end 时间范围 flag，
// 查询时折叠为 <paramKey>[0] / <paramKey>[1] 数组参数。
// flagName 为 kebab-case（如 "load-date"），paramKey 为 camelCase（如 "realLoadDate"）。
func AddTimeRangeFlags(c *cobra.Command, flagName, paramKey, label string) {
	c.Flags().String(flagName+"-start", "", label+"起（如 2026-07-01 00:00:00）")
	c.Flags().String(flagName+"-end", "", label+"止（如 2026-07-31 23:59:59）")
}

// CollectTimeRangeFlags 把非空的 --<flagName>-start/end 折叠为 <paramKey>[0]/[1]。
func CollectTimeRangeFlags(cmd *cobra.Command, params map[string]any, flagName, paramKey string) {
	if v, _ := cmd.Flags().GetString(flagName + "-start"); v != "" {
		params[paramKey+"[0]"] = v
	}
	if v, _ := cmd.Flags().GetString(flagName + "-end"); v != "" {
		params[paramKey+"[1]"] = v
	}
}
```
